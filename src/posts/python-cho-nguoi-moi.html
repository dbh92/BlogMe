Python nổi tiếng với cú pháp gần với tiếng Anh tự nhiên, được dùng trong phân tích dữ liệu, trí tuệ nhân tạo, tự động hóa và lập trình web. Nếu bạn chưa từng viết một dòng code nào, Python là lựa chọn khởi đầu tuyệt vời. Trong bài này, chúng ta sẽ đi qua 4 khái niệm nền tảng có mặt trong mọi ngôn ngữ lập trình.

Cài đặt Python

Tải bản mới nhất tại python.org. Trên Windows, nhớ tích chọn "Add Python to PATH" khi cài. Kiểm tra bằng lệnh:

python --version

Nếu chưa muốn cài đặt, bạn có thể dùng Google Colab hoặc các trang chạy Python trực tuyến.

1. Biến và kiểu dữ liệu

Biến giống như chiếc hộp có dán nhãn để chứa dữ liệu. Python tự nhận biết kiểu dữ liệu, bạn không cần khai báo.

ten = "Hoa"            # chuỗi (str)
tuoi = 22              # số nguyên (int)
diem_tb = 8.5          # số thực (float)
da_tot_nghiep = False  # đúng/sai (bool)
so_thich = ["đọc sách", "code", "du lịch"]  # danh sách (list)

print(f"{ten} năm nay {tuoi} tuổi, điểm trung bình {diem_tb}")

2. Câu điều kiện if / elif / else

Chương trình cần ra quyết định dựa trên dữ liệu. Lưu ý: Python dùng thụt lề (4 dấu cách) thay cho dấu ngoặc nhọn.

diem = float(input("Nhập điểm của bạn: "))

if diem >= 8:
    print("Giỏi")
elif diem >= 6.5:
    print("Khá")
elif diem >= 5:
    print("Trung bình")
else:
    print("Cần cố gắng thêm")

3. Vòng lặp for và while

Vòng lặp giúp lặp lại công việc mà không phải viết code nhiều lần.

# In bảng cửu chương 7
for i in range(1, 11):
    print(f"7 x {i} = {7 * i}")

# Duyệt danh sách
for mon in so_thich:
    print("Tôi thích", mon)

# Vòng lặp while
so_lan = 3
while so_lan > 0:
    print("Đếm ngược:", so_lan)
    so_lan -= 1

4. Hàm (function)

Hàm đóng gói một đoạn code để tái sử dụng. Đây là bước đầu tiên để viết chương trình gọn gàng.

def tinh_bmi(can_nang, chieu_cao):
    """Tính chỉ số BMI từ cân nặng (kg) và chiều cao (m)."""
    return can_nang / (chieu_cao ** 2)

bmi = tinh_bmi(60, 1.68)
print(f"BMI của bạn là {bmi:.1f}")

Bài tập tự luyện

  1. Viết chương trình nhập vào một số và cho biết số đó chẵn hay lẻ.
  2. In ra tất cả số nguyên tố nhỏ hơn 100.
  3. Viết hàm dao_nguoc(chuoi) trả về chuỗi đảo ngược.
  4. Làm trò chơi đoán số: máy chọn ngẫu nhiên từ 1 đến 100, người chơi đoán đến khi đúng (gợi ý: dùng import random).
Lập trình là kỹ năng, không phải kiến thức. Bạn không thể học bơi bằng cách đọc sách, hãy gõ code mỗi ngày dù chỉ 30 phút.
