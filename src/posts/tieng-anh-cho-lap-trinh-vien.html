Khoảng 90% tài liệu lập trình, thông báo lỗi và câu trả lời trên Stack Overflow đều bằng tiếng Anh. Bạn không cần giỏi ngữ pháp để làm lập trình viên, nhưng vốn từ vựng chuyên ngành sẽ quyết định tốc độ học và làm việc của bạn. Dưới đây là 50 thuật ngữ được chia theo ngữ cảnh sử dụng.

Nhóm 2: Lỗi và gỡ lỗi

  • bug: lỗi; debug: gỡ lỗi
  • exception: ngoại lệ; throw / catch: ném / bắt ngoại lệ
  • stack trace: dấu vết ngăn xếp, chuỗi lời gọi hàm dẫn tới lỗi
  • undefined / null: chưa được định nghĩa / rỗng
  • deprecated: đã lỗi thời, sắp bị loại bỏ
  • workaround: cách giải quyết tạm thời
  • reproduce: tái hiện lỗi
  • breakpoint: điểm dừng khi debug
  • edge case: trường hợp biên, hiếm gặp
  • timeout: hết thời gian chờ

Nhóm 3: Quy trình làm việc

  • requirement: yêu cầu; specification (spec): đặc tả
  • deadline: hạn chót; estimate: ước lượng thời gian
  • sprint / backlog: chu kỳ phát triển / danh sách việc tồn đọng (Agile)
  • pull request (PR): yêu cầu gộp code; code review: rà soát code
  • merge conflict: xung đột khi gộp code
  • deploy / release: triển khai / phát hành
  • rollback: quay lại phiên bản trước
  • staging / production: môi trường thử nghiệm / môi trường thật
  • refactor: tái cấu trúc code mà không đổi chức năng
  • technical debt: "nợ kỹ thuật", những chỗ làm tạm cần sửa sau

Nhóm 4: Web và hệ thống

  • frontend / backend: phần giao diện / phần xử lý phía máy chủ
  • request / response: yêu cầu / phản hồi
  • endpoint: địa chỉ API cụ thể
  • authentication / authorization: xác thực (bạn là ai) / phân quyền (bạn được làm gì)
  • database / query: cơ sở dữ liệu / truy vấn
  • cache: bộ nhớ đệm
  • scalability: khả năng mở rộng
  • latency: độ trễ
  • framework / library: khung phát triển / thư viện
  • dependency: thư viện phụ thuộc

Mẫu câu giao tiếp hay dùng

  • "Could you take a look at my PR when you have time?": Anh/chị xem giúp PR của em khi rảnh nhé?
  • "I can't reproduce this bug on my machine.": Tôi không tái hiện được lỗi này trên máy mình.
  • "It works on staging but fails on production.": Chạy được ở staging nhưng lỗi ở production.
  • "I'll push a fix by the end of the day.": Tôi sẽ đẩy bản sửa trước cuối ngày.
  • "Let's sync up tomorrow morning.": Mai mình họp nhanh buổi sáng nhé.
